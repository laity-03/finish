# STM32 雪糕棒角度闭环控制框架

## 1. 系统结构

控制链：

```text
MPU6050 姿态角(roll)
        -> 角度 PID
        -> 目标转速(RPM)
        -> 编码器速度反馈
        -> 速度 PID
        -> PWM
        -> TB6612
        -> TT 电机
        -> 雪糕棒
```

两种控制模式：

- `ANGLE`：角度外环 + 速度内环，雪糕棒保持指定绝对角度。
- `SPEED`：直接使用速度环控制电机输出轴转速，供按键和 VOFA 调速测试使用。

默认控制节拍为 `10 ms`，即 `100 Hz`。主循环会测量实际控制间隔并用于 PID `dt` 和编码器速度计算，以补偿 OLED/UART 短时阻塞。

## 2. 引脚分配

| 引脚 | 外设/功能 | 连接对象 | 说明 |
|---|---|---|---|
| PA0 | TIM2_CH1 | 编码器 A 相 | 定时器编码器接口，内部上拉 |
| PA1 | TIM2_CH2 | 编码器 B 相 | 定时器编码器接口，内部上拉 |
| PA2 | GPIO 输入 | 速度按键另一端接 GND | 内部上拉，低电平按下 |
| PA3 | GPIO 输入 | 角度按键另一端接 GND | 内部上拉，低电平按下 |
| PA4 | ADC1_IN4 | 模拟旋钮模块 OUT | 0~3.3 V 对应 -75°~+75° |
| PA8 | TIM1_CH1 PWM | TB6612 PWMA | 10 kHz PWM，占空比 0~100 |
| PA9 | USART1_TX | USB-TTL RX | VOFA+，115200 8N1 |
| PA10 | USART1_RX | USB-TTL TX | 接收 VOFA+ 命令 |
| PB6 | I2C1_SCL | MPU6050 SCL | 400 kHz |
| PB7 | I2C1_SDA | MPU6050 SDA | 400 kHz |
| PB10 | I2C2_SCL | OLED SCL | 400 kHz |
| PB11 | I2C2_SDA | OLED SDA | 400 kHz |
| PB12 | GPIO 输出 | TB6612 AIN1 | 电机方向 1 |
| PB13 | GPIO 输出 | TB6612 AIN2 | 电机方向 2 |
| GND | 电源地 | 所有模块共地 | 必接 |
| 5V | 外接稳定 5V | TB6612 VCC/VM/STBY | 按考核题要求，不要用 12V 或电脑口 5V |

TB6612 的 `AO1/AO2` 接 TT 电机，`STBY` 必须保持高电平。当前代码不控制 STBY，硬件需要将 STBY 接到 5V，或后续增加专用 GPIO 控制。

OLED 使用独立 I2C2：`SCL -> PB10`，`SDA -> PB11`。PB10/PB11 为开漏总线，线路必须有上拉；多数 OLED 模块自带 4.7k 上拉，若模块没有上拉，请在 SCL/SDA 到 3.3V 各接 4.7k 电阻。

## 3. 定时器与外设参数

| 外设 | 参数 | 用途 |
|---|---|---|
| TIM1 | PSC=71，ARR=99 | 72 MHz 时钟下产生 10 kHz PWM |
| TIM2 | 编码器模式 TI12，ARR=65535 | 四倍频读取电机编码器 |
| TIM3 | PSC=7199，ARR=9 | 1 ms 中断节拍 |
| 控制分频 | TIM3 每 10 次中断 | 10 ms 控制周期 |
| USART1 | 115200，8 数据位，1 停止位，无校验 | VOFA+ 遥测和命令 |
| I2C1 | 400 kHz | MPU6050 |
| I2C2 | 400 kHz | OLED |

## 4. MPU6050 安装与角度定义

- MPU6050 必须固定在雪糕棒上，不能只固定在电机外壳上。
- 默认假设 MPU6050 的 X 轴与电机输出轴平行，因此使用 `roll` 作为雪糕棒角度。
- 若实际安装方向不同，在 `Core/Inc/control.h` 中把 `CONTROL_ANGLE_USE_ROLL` 改为 `0`，改用 `pitch`。
- 上电时把雪糕棒保持在你希望定义为 `0°` 的位置，程序会等待约 1 秒并记录零点。
- `CONTROL_ANGLE_SIGN` 用来保证“电机正向转动时实际角度增加”。
- 角度目标范围为 `-75° ~ +75°`，防止接近欧拉角奇异区域。

## 5. VOFA+ 配置

VOFA+ 串口设置：

```text
协议：JustFloat
波特率：115200
数据位：8
停止位：1
校验：无
通道数：14
刷新频率：20 Hz
```

14 个通道含义：

| 通道 | 数据 | 单位/说明 |
|---:|---|---|
| 1 | mode | 0=ANGLE，1=SPEED |
| 2 | target_angle | 目标角度 ° |
| 3 | actual_angle | 实际角度 ° |
| 4 | target_speed | 目标转速 RPM |
| 5 | actual_speed | 实际转速 RPM |
| 6 | pwm_output | PWM 输出，-100~100 |
| 7 | roll | MPU6050 roll ° |
| 8 | pitch | MPU6050 pitch ° |
| 9 | yaw | MPU6050 yaw ° |
| 10 | gyro_x | 角速度 X，°/s |
| 11 | gyro_y | 角速度 Y，°/s |
| 12 | gyro_z | 角速度 Z，°/s |
| 13 | encoder_turns | 编码器输出轴圈数（原始计数 / 1320） |
| 14 | mpu_ok | MPU6050 在线状态：1=正常，0=没读到 |

## 6. VOFA+ 下行命令

每条命令以回车或换行结束。

| 命令 | 示例 | 功能 |
|---|---|---|
| `A<角度>` 或 `A=<角度>` | `A30` | 设置目标角度 30°，并切到角度模式 |
| `R<转速>` 或 `R=<转速>` | `R60` | 设置目标转速 60 RPM，并切到速度模式 |
| `S<转速>` | `S-30` | `R` 的别名，设置速度目标 |
| `M=A` 或 `MA` | `M=A` | 切换到角度模式 |
| `M=R`、`M=S` | `M=R` | 切换到速度模式 |
| `Z` | `Z` | 把当前雪糕棒位置记录为 0°，目标角设为 0° |

示例：

```text
A30      雪糕棒目标角 30°
A-20     雪糕棒目标角 -20°
R60      电机目标转速 60 RPM
R-60     电机目标转速 -60 RPM
M=A      返回角度闭环
Z        当前姿态清零
```

## 7. 双按键控制

两个按键都是一端接引脚，另一端接 GND，使用内部上拉，低电平按下。

### 7.1 速度按键（PA2）

- 短按：切换到 `SPEED` 模式，并循环以下转速档位：

```text
0 -> 30 -> 60 -> 100 -> -30 -> -60 -> -100 RPM -> 0 ...
```

- 长按超过 `800 ms`：返回 `ANGLE` 角度闭环模式。

### 7.2 角度按键（PA3）

- 短按：切换/保持在 `ANGLE` 模式，并循环以下目标角度档位：

```text
0 -> 10 -> 30 -> 60 度 -> 0 ...
```

- 长按超过 `800 ms`：目标角度直接回到 `0°`。
- 档位表下标与目标角同步：上电、`Z` 清零命令后都回到 `0°` 档。

### 7.3 消抖

- 消抖时间：30 ms。

### 7.4 模拟旋钮控制

模拟旋钮模块接线：

```text
旋钮 VCC -> 3.3 V
旋钮 GND -> GND
旋钮 OUT -> PA4
```

如果旋钮板上没有 `OUT`，只能接触到电位器本体的 `A/C/B` 三个端子，则接：

```text
A -> 3.3 V
B -> GND
C -> PA4
```

交换 `A/B` 可以反转旋钮方向。若板上已经有 `VCC/OUT/GND` 三针排针，底部
`A/C/B` 是电位器本体焊盘，不用再重复接线。

`PA4` 对应 `ADC1_IN4`。程序将 ADC 原始值 `0~4095` 映射为目标角
`-75°~+75°`，中点约对应 `0°`。旋钮值变化后切回角度模式并更新目标角；
目标角按 `90°/s` 限速跟随，避免快速扭动时电机猛冲。不转旋钮时，
原来的按键和 VOFA+ 命令仍然有效。OLED 第四行的 `K:` 显示旋钮 ADC 原始值，
顺时针旋转时应平滑变化；如果固定在 `0`、`4095` 或剧烈跳动，说明 `OUT`
没有正确接到 PA4，程序会忽略这个无效输入。

旋钮 ADC 在 `Core/Src/knob.c` 中手动初始化，和 `AIN1/AIN2` 一样不依赖
CubeMX 生成代码，因此重新生成工程后不需要重新配置 PA4。不要把旋钮 VCC
接到 5 V 后再把 OUT 直接接 PA4，否则可能超过 STM32 ADC 输入范围。

控制停止死区为 `1°`，转速死区为 `2 RPM`。进入死区后程序会清掉两个 PID
积分并关闭 PWM，减少雪糕棒在目标角附近来回抖动。

## 8. OLED 显示

OLED 使用独立的 I2C2（SCL=PB10，SDA=PB11），地址 `0x78`，显示四行数据：

```text
ANG T:<目标角> A:<实际角>
ERR:<角度误差>
SPD:<目标转速>/<实际转速>
PWM:<输出>
```

`SPD` 模式时第一行显示 `SPD`，其它行仍显示实时数据。OLED 刷新频率约为 5 Hz，避免整屏 I2C 刷新长时间阻塞控制主循环。

## 9. PID 和速度参数

| 项目 | 参数 |
|---|---|
| 角度环 Kp | 2.5 |
| 角度环 Ki | 0.50 |
| 角度环 Kd | 0.08 |
| 角度环输出范围 | -80 ~ +80 RPM |
| 角度环积分限幅 | 80 |
| 速度环 Kp | 1.0 |
| 速度环 Ki | 1.5 |
| 速度环 Kd | 0 |
| 速度环输出范围 | -100 ~ +100 PWM |
| 速度环积分限幅 | 100 |
| 角度死区 | 0.3° |
| 速度死区 | 1 RPM |
| 速度低通系数 | 0.35 |

编码器换算：

```text
ENCODER_COUNTS_PER_OUTPUT_REV = 1320
```

该默认值表示 `11 PPR × 4 倍频 × 30 减速比`。如果电机规格不同，需要通过 VOFA 观察第 16 通道，手动转动输出轴一圈，记录计数增量后修改 `Core/Inc/encoder.h`。

## 10. 标定与方向检查

1. 将雪糕棒放在希望的 0° 位置，再给系统上电。
2. 等待 MPU6050 陀螺仪校准和角度零点记录完成。
3. 让电机停止，手动绕电机轴转动雪糕棒，在 VOFA 中观察 `roll` 和 `pitch`。
4. 若 `roll` 变化最明显，保持 `CONTROL_ANGLE_USE_ROLL=1`；若 `pitch` 变化最明显，改为 `0`。
5. 在速度模式发送 `R30`，确认编码器第 17 通道速度为正；如果为负，修改 `ENCODER_DIRECTION_SIGN`。
6. 在角度模式发送 `A10`，确认雪糕棒朝向目标方向运动。如果方向反了，修改 `CONTROL_ANGLE_SIGN`。
7. 先调速度环，再调角度环。不要同时大幅修改角度环和速度环。
